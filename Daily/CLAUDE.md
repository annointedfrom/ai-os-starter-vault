# Daily — Layer 2

> ⬆ Parent: [[../CLAUDE|Layer 1]]

## Purpose

One note per day, named `YYYY-MM-DD.md`, made from `_templates/daily-note.md`.
It records what actually happened, so `/start` and future sessions can pick up the thread.

## Rules

1. **Append, never overwrite.** Claude adds to today's note; it never rewrites past days.
2. **Short beats complete.** A few lines of "did / decided / next" is enough.
3. **A missing daily note is a signal.** `/start` points it out.
4. **Weekly review (optional):** summaries go in `Daily/weekly/YYYY-Www.md`.

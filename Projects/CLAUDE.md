# Projects — Layer 2

> ⬆ Parent: [[../CLAUDE|Layer 1]]

## Purpose

Active work with a goal and an end: a product, a course project, a launch.
Ongoing responsibilities belong in `Areas/`; code lives in `Sandbox/` or the project's own repo.

## Rules

1. **Every project gets its own `CLAUDE.md`.** Copy `_example-project/` to start one.
2. **List it in the Layer-1 projects table** so a fresh session knows it exists.
3. **Record decisions here, not in chat.** When a session decides something, add it to the project's "Decisions" section.
4. **Finished?** Move the folder to `Archive/` and remove it from the Layer-1 table.

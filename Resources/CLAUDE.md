# Resources — Layer 2

> ⬆ Parent: [[../CLAUDE|Layer 1]]

## Purpose

Reference material you want to find again: tool setup notes, saved research, cheat sheets,
links, and notes about the AI tools you use with this vault.

## Rules

1. **Reference, not active work.** If you're building it, it belongs in `Projects/` or `Sandbox/`.
2. **No secrets.** Keys, tokens and service-account files stay outside the vault.
3. **Cite sources.** Research notes keep the URL and the date you read it.
4. **Big topics get their own subfolder and Layer-2 `CLAUDE.md`** (for example `Resources/local-ai/`).

## Suggested subfolders

| Folder | For |
|---|---|
| `tools/` | setup notes for each tool (Claude Code, Obsidian plugins, local models) |
| `research/` | dated research briefs with sources |
| `links/` | bookmarks by topic |
